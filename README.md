## 📌 Sobre o projeto

O **MovieCity** é uma Landing Page de filmes desenvolvida como atividade prática do curso Técnico em Desenvolvimento de Sistemas.

O objetivo é aplicar os fundamentos do React na construção de uma interface organizada, visualmente atrativa e responsiva, utilizando componentes, imagens e estilização com CSS.

## ✨ Funcionalidades

- 🎥 Apresentação visual de filmes e pôsteres.
- 🧭 Cabeçalho com logo e navegação.
- 🧩 Interface dividida em componentes reutilizáveis.
- 🖼️ Importação e exibição de imagens.
- 📱 Layout adaptável a diferentes tamanhos de tela.
- 🎨 Estilização com CSS3.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| React | Construção dos componentes |
| Vite | Criação e execução do projeto |
| JavaScript | Lógica da aplicação |
| CSS3 | Estilização e responsividade |
| npm | Gerenciamento de dependências |

## 🚀 Como executar o projeto

**1.** Acesse a pasta do projeto pelo terminal.

**2.** Instale as dependências:

```bash
npm install
```

**3.** Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

**4.** Abra no navegador o endereço exibido no terminal, normalmente `http://localhost:5173`.

> Para criar o projeto do zero, utilize `npm create vite@latest .` dentro da pasta destinada ao projeto e selecione React com JavaScript.

## 📱 Responsividade e testes

O projeto deve ser verificado em diferentes resoluções para garantir uma boa experiência em computadores, tablets e celulares.

- [ ] Executar a aplicação sem erros.
- [ ] Verificar o carregamento das imagens.
- [ ] Conferir a organização dos componentes.
- [ ] Testar a navegação e os elementos visuais.
